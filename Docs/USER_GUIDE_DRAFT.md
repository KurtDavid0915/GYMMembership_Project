# GymTrack CLI – User Guide

## Installation
### Prerequisites
- Node.js
- npm

### Setup
1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Usage Instructions

### Add Member
npm start add-member "Juan Dela Cruz" --phone 09123456789

### Subscribe Member
npm start subscribe-member --member 1 --plan 1

### Check-in
npm start check-in --member 1

### Export Data
npm start export-json
